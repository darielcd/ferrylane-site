Ferrylane Privacy Policy

Effective November 6, 2026 · Ferrylane by Dariel Candelario

Ferrylane is an FTP, FTPS and SFTP file transfer client for Windows. In short: Ferrylane does not collect, sell or share any of your information, and sends nothing to its developer. Everything it saves stays on your PC.

What Ferrylane stores on your PC

To do its job, Ferrylane saves the following in its data folder on your computer:

  • Saved sites: server addresses, ports, user names, start folders and the path of any key file you choose.
  • Saved passwords and key passphrases, only if you choose to save them. They are encrypted with Windows Data Protection for your Windows account, or with your master password (AES-256) if you turn that on. Your master password itself is never stored.
  • Trusted server keys and certificates, so Ferrylane can warn you if a server's identity changes.
  • Settings such as theme and transfer options.
  • Log files with server names, folder and file names and transfer results, to help you troubleshoot. Logs never contain passwords and are deleted automatically after 14 days.

This information never leaves your PC unless you copy it yourself. Uninstalling Ferrylane from the Microsoft Store removes it.

What Ferrylane sends over the network

Ferrylane connects only to the servers you add or type in. It sends your user name, password or key to that server to log in, and transfers the files you choose. With SFTP or FTPS these are encrypted in transit; plain FTP is not encrypted, so use SFTP or FTPS whenever the server supports it.

Ferrylane does not contain analytics, advertising, tracking or telemetry, and it does not contact the developer or any other service.

Microsoft Store

If you get Ferrylane from the Microsoft Store, Microsoft handles the download, purchase and updates, and may collect information under the Microsoft Privacy Statement. The developer only receives the aggregate, anonymous reports Microsoft provides to all app publishers (for example, number of installs and crash counts).

Children

Ferrylane is a general-purpose tool and does not knowingly collect information from anyone, including children.

Changes

If this policy changes, the new version will be posted on this page with a new effective date.

Contact

Questions about this policy can be sent through the support options on Ferrylane's Microsoft Store page.
